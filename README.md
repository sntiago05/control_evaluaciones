# Control de evaluaciones

Aplicación de escritorio en **JavaFX** para calcular promedios de evaluaciones de alumnos. Aplica distintas reglas de cálculo según el tipo de promedio.

## Modelo
- `PromedioAbstract`: base común de los cálculos.
- `PromedioRegular` y `PromedioPregrado`: reglas de cálculo distintas.
- `Condicion` y `Alumno`: estado académico del estudiante.

## Tecnologías
Java, JavaFX (FXML), ControlsFX, Maven.

## Cómo ejecutar
Abre el proyecto en tu IDE y ejecuta `PrincipalAplication` (paquete `app`), o usa el plugin de JavaFX de Maven.

## Proyecto de aprendizaje
Práctica de herencia/polimorfismo y separación de vista (FXML) y controlador.
